# Component Photo Asset Slots

You can easily replace the provided vector SVG illustrations with your actual project photos. Simply drop your photos into this folder (`public/assets/components/`) using any of the matching filenames:

1. `esp32.jpg` or `esp32.png` / `esp32.svg` - ESP32 DevKit V1 Board
2. `hw038.jpg` or `hw038.png` / `hw038.svg` - HW-038 Water Level Sensor Probes (LOW & FULL)
3. `turbidity.jpg` or `turbidity.png` / `turbidity.svg` - Optical Turbidity Sensor & Conditioning Board
4. `ir-sensor.jpg` or `ir-sensor.png` / `ir-sensor.svg` - IR Obstacle Detection Sensor Module
5. `relay.jpg` or `relay.png` / `relay.svg` - 5V Optocoupler Dual-Channel Relay Module
6. `solenoid.jpg` or `solenoid.png` / `solenoid.svg` - 12V DC Normally-Closed Mini Solenoid Valve
7. `pump.jpg` or `pump.png` / `pump.svg` - Mini DC Submersible Water Pump
8. `buzzer.jpg` or `buzzer.png` / `buzzer.svg` - 5V Active Piezo Buzzer
9. `leds.jpg` or `leds.png` / `leds.svg` - Red (Alarm) & Green (Healthy) 5mm Status LEDs
10. `resistor.jpg` or `resistor.png` / `resistor.svg` - Resistor for 5V-to-3.3V ADC Voltage Divider

The UI automatically handles both vector `.svg` and photographic `.jpg` / `.png` formats.
